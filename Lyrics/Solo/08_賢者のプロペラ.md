# 難関  
あるミャンマー人が私に言った。  
「あなたはミャンマーの錬金術師に会うべきだ」  
「あなたは秘密めいた事を考え、人々を楽しませている」  
「あなたはきっと錬金術の秘儀を理解し、すぐに銅を作り出すことができるはずだ」。  
  
光栄だが、それは全く過大評価だ。  
  
私は、隠喩としての「銅」程の価値すら持ちあわせない「俗人」だが、  
「ヒラサワ」の世間体を形作る「音楽」の力が、  
かのミャンマー人に世離れした印象を与えたのだろう。  
しかし、それは少しも不思議なことでは無い。  
音楽は、一人の俗人の中にすら「黄金」を予感させる。  
  
しかし、我々はこの100年、その「黄金」にかまける時間を与えられなかった。  
“黄金”(所有の対象となる魅惑の物質たち)が量産され、  
我々を「良き消費者」として24時間包囲し続けたからだ。  
この馬鹿げた世紀から学び、もしあなたが21世紀へ渡ろうとするなら、  
次の難関に挑まなければならない。  
  
黄金への到達に不可欠、かつその発見は最大の難関とされる「賢者の石」。  
その代替品を今世紀の技術は量産できたのか?  
回転する樹脂盤を電子の炉に入れ、そこから自らの黄金を取り出すこと。  
  
しかし、音楽は今もなお、代替錬金術である。  
  
--平沢進  
  
# 难关  
一位缅甸人对我说：  
“你应该去见见缅甸的炼金术士。”  
“你思考着神秘之事，同时取悦着人们。”  
“你肯定能领悟炼金术的奥秘，立刻炼出铜来。”  
  
虽然很荣幸，但这完全是过誉了。  
  
我不过是连作为隐喻的“铜”之价值都不具备的俗人，  
然而，构筑“平泽”这一社会形象的“音乐”之力，  
却让那位缅甸人感到一种超脱尘世的印象。  
但是, 这一点都不神奇。  
音乐，甚至能让一个俗人之中显现出“黄金”的预感。  
  
然而，我们在过去的一百年，却没有被给予用于沉浸在那“黄金”中的时间。  
“黄金”（能被拥有的魅惑之物）被量产，
将我们当作“良好消费者”24小时持续包围。  
从这荒谬的世纪中反思，若你试图迈向21世纪的话，  
就必须挑战新的难关。  
  
通往黄金不可或缺、且将其发现正是最大难关的“贤者之石”。  
当代技术能够量产它的替代品吗？  
将旋转的树脂盘投入电子之炉中，从中提取属于你自己的“黄金”。  
  
而音乐，至今仍是炼金术的替代。  
  
——平泽进

その輝きと、金属としての不変性により、  
古来「生命の反映、永遠の象徴」として尊重された。  
金貨の材料でもあったため、錬金術の歴史には大量のペテンが紛れ込んだ。  
ユング派では、個性化の完成、内なる自己の発見に関連付けられることがある。  
  
[達人]  
大いなる秘儀に達した人。  
賢者の石(究極の叡智、黄金の製造を媒介する物質)を発見した錬金術師。  
  
[作業]  
金属変成作業は、黒化→白化→赤化の3工程を基本として行われた。  
また、金属が変化していく作業の工程は、同時に錬金術師の精神が浄化していく過程でもある。  
錬金術師にとって変成の真の舞台は、魂の内にあった。  
  
[ニグレド・アルベド・ルベド]  
いずれも作業の段階を指し、それぞれ前述の「黒化」 「白化」 「赤化」に対応する。  
錬金術師の精神は、ニグレドにおいては「内なる闇」と対話し、 アルベドにおいて「茫漠たる光」に出会い、ルベドに至って「黄金のごとくに輝ける洞察」に達する。  
  
[ロタティオン]  
錬金作業の最終工程は最初の工程へと回帰し、発展的円環、すなわち螺旋をなす。  
永遠に繰り返されるこの輪廻をロタティオンと呼ぶ。  
  
[円積法]  
「円を正方形に分解してその積を求める方法」から転じて「解答困難な難問題」を意味する。 より狭義には、錬金術的難問である「男性原理と女性原理の統合」を指した。  
  
[課題が見出される庭園]  
作者不詳の錬金術の文献、荒れ果てた庭園の中にも、植物の生成と衰減、  
その循環といった錬金術的神秘を見ることができる。  
そしてそこには、秘儀に近づくための課題もまた無数にあふれている。  
  
# 关于炼金术 --高野真 (AI翻译+修改)  
  
从字面意义上说，炼金术指的是将卑金属转化为贵金属，  
尤其是制造黄金的技艺，  
并且也包括制作长生不老之药和万能药的技术。  
其本质，则是一种以净化灵魂、转化精神为目的的哲学实践。  
  
它的源头几乎可以追溯到所有古代文明，  
但在从希腊化时代到中世纪的欧洲以及伊斯兰世界中尤为发展，  
并在化学史、思想史、美术史、文学史等领域留下了深远的足迹。  
  
由于以神秘的隐喻所书写的秘仪极其晦涩难解，  
也因此在大多数现代人眼中，它不过是陈腐过时的遗物，  
然而，炼金术的哲学成果在现代依然  
具有现实意义，  
尤其是对荣格学派心理学产生了极其深远的影响。  
  
而且最重要的是——  
那位用计算机取代中世纪实验器具进行操作的  
“那位”“永恒之音的司祭”，  
也正是在当下体现着古代贤者的姿态。  
不仅体现在其充满象征与启示的创作风格上，  
也体现在他在完成之前首先追求“混沌（Chaos）”的态度之中，  
甚至还体现在那略显忧郁的面容之上。  
  
<br><br>  
  
【黄金】  
由于其光辉以及作为金属的不变性，  
自古以来被视为“生命的映照、永恒的象征”。  
由于也是金币的材料，炼金术的历史中混入了大量骗局。  
在荣格学派中，它有时被视为个体化完成、内在自我的发现的象征。  
  
【达人】  
达到伟大秘仪之人。  
即发现了“贤者之石”（究极智慧、促成黄金生成的媒介物）的炼金术师。  
  
【作业】  
金属变成（转化）的过程，基本分为三阶段： 黑化 → 白化 → 赤化。  
同时，这一金属变化的过程，也象征着炼金术师精神逐渐净化的过程。  
对于炼金术师而言，真正的转化舞台，存在于灵魂之中。  
  
【Nigredo / Albedo / Rubedo】  
均指作业的阶段，分别对应前述的： 黑化 / 白化 / 赤化。  
炼金术师的精神在：  
Nigredo（黑化）：与“内在的黑暗”对话  
Albedo（白化）：邂逅“茫然广阔的光”  
Rubedo（赤化）：抵达“如黄金般闪耀的洞察”  
  
【Rotation】  
炼金作业的最终阶段会回归到最初阶段，形成一种不断发展的循环——也就是螺旋结构。  
这种永恒重复的轮回，被称为“Rotation”。  
  
【圆积法】  
原意为“将圆分解为正方形并求其面积的方法”，引申为“难以解答的难题”。  
在更狭义上，指炼金术中的难题：男性原理与女性原理的统一  
  
【发现课题的庭园】  
一部作者不详的炼金术文献。  
即使在荒芜的庭园之中，也能看到植物的生成与衰减，  
以及那种循环所呈现的炼金术般的神秘。  
而在那里，也充满了无数通向秘仪的“课题”。
